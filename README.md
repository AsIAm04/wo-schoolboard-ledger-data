# wo-schoolboard-ledger-data

Meeting transcripts for the West Orange Board of Education, structured as JSON. Data source for
the school board ledger site (sibling to `wo-ledger-data`, which backs the Township Council
Ledger at asiamconsultinggroup.com/the-town-ledger).

97 meetings, 2021–2026. See `SCHEMA.md` for record format and known caveats.

Source: full meeting transcripts already collected locally (not an automated scrape — no source
URL per record, unlike the council data which pulls from westorange.org/agendacenter).
